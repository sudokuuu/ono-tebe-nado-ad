# Оно тебе надо — аукцион вещей, в которые никто не верил

Одностраничный сайт-аукцион, посвящённый вещам, которые когда-то казались неудачными, а сейчас стали культовыми.

## О проекте

Проект создан в рамках первого спринта курса по фронтенд-разработке. Это статичная вёрстка по макету Figma с использованием семантической разметки, Flexbox и Grid.

На сайте представлены:
- **Шапка** с навигацией, логотипом и контактной информацией
- **Обложка** с крупным заголовком и кнопкой призыва к действию
- **Секция «Лоты»** с тремя карточками (фильм, книга, картина)
- **Секция «Об аукционе»** с описанием идеи проекта
- **Подвал** с адресом, меню и ссылками на социальные сети

## Стек технологий

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox, Grid, кастомные шрифты, фоновые изображения
